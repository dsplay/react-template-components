# DSPLAY React template components

> **Retired.** This package is deprecated on npm and this repo is archived. Its one real
> component, `GridGallery`, has been ported to
> [`@dsplay/react-template-utils`](https://www.npmjs.com/package/@dsplay/react-template-utils)
> (plain JS + JSDoc, same API) — that's now the single React component/hooks library for
> DSPLAY templates. Use that package instead; nothing here should be built upon further.

React components for building DSPLAY templates

## Usage

To install dependencies
``` 
$ yarn install
```

To build
```
$ yarn build 
```

To run tests
```
$ yarn test
```

To run Storybook
``` 
$ yarn storybook
```
